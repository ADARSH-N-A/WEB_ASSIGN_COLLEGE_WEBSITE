# Department of CSE Website (HTML5)

Simple multi-section college department website built with plain HTML5 and a little CSS.

**Author:** Adarsh N A | Roll No: 9 | S7 CSE A | Web Programming

## Files
- `index.html` - the website (header, nav, main sections, form, footer)
- `css/style.css` - styling
- `images/logo.svg` - department logo
- `report.tex` - LaTeX source of the report

## Run
Open `index.html` in any browser. No build step needed.
